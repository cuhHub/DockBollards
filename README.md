# cuhHub - Dock Bollards

## 📚 Overview
An addon providing dock bollards at docks around the map. Ripped from base-game dock bollards addon.

## ⚙️ Setup
⚠️ [cuhkit](https://github.com/cuhHub/cuhkit) is required.

1) Run `git clone https://github.com/cuhHub/DockBollards`.
2) Run `cuhkit setup`.
3) Run `cuhkit build`. Do this for every change to the code.
4) Run the addon in a save and all should work.
